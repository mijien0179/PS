# [이분 그래프](https://www.acmicpc.net/problem/1707)

그래프의 임의 지점을 선택해 들어올렸을 때, 동일 차수에 있는 정점이 같은 색으로 칠해질 수 있는지를 판단하는 문제이다.  
`K`개의 테스트 케이스가 주어지고, 각 테스트 케이스에서 그래프는 1개 이상이다.  

## 해결

현재 정점과 직접 연결된 정점을 검색하고, 검색된 정점에 현재 정점과 다른 값 `alpha`를 넣어준다.  
이 과정을 거치면서 검색된 정점이 초기값이 아니면서 `alpha`값과 같지 않은 경우 이분 그래프가 아니라고 판단한다.

주어진 조건에서 `주어지는 그래프는 하나다` 라는 조건이 없어 전체 그래프에 대해 판별하지 않을 경우 AC를 받을 수 없는 문제가 있었다.

```cpp
#include <iostream>
#include <vector>
#include <queue>

#define endl "\n"

using namespace std;

constexpr int INITIAL = -1;

inline int getNextColor(int color) {
	if (color == 1) return 2;
	return 1;
}

void solution() {
	int V, E, u, v;
	cin >> V >> E;

	vector<vector<int>> path(V + 1);
	for (int i = 0; i < E; ++i) {
		cin >> u >> v;
		path[u].push_back(v);
		path[v].push_back(u);
	}


	vector<int> color(V + 1, INITIAL);
	bool bipartiteGraph = true;
	for (int i = 1; i < color.size() && bipartiteGraph; ++i) {
		if (color[i] != INITIAL) continue;

		queue<pair<int, int>> q;
		color[i] = 1;
		q.emplace(i, 1);

		while (q.size() && bipartiteGraph) {
			auto [current, currentColor] = q.front(); q.pop();

			for (const auto v : path[current]) {
				const auto nextColor = getNextColor(currentColor);

				if (color[v] == INITIAL) {
					color[v] = nextColor;
					q.emplace(v, nextColor);
					continue;
				}

				if (color[v] != nextColor) {
					bipartiteGraph = false;
					break;
				}
			}
		}


	}

	cout << (bipartiteGraph ? "YES" : "NO") << endl;
}

int main() {
	cin.tie(0)->sync_with_stdio(0);
	cout.tie(0);

	int K;
	cin >> K;

	while (K--) {
		solution();
	}
}
```

## Testcase

아래 입력은 `주어지는 그래프가 하나인가`에 대한 테스트 케이스이다.  
아래 입력은 `{1, 2}` 그래프와 `{3, 4, 5}` 그래프로 분리되어있다.

5 4
