# [공유기 설치](https://www.acmicpc.net/problem/2110)

아직 이런 문제가 약하구나 싶다. 단순히 이진 탐색을 이용하는 문제는 웬만하면 풀 수 있는데, 이 문제의 경우에는 이진 탐색은 부차적이고, 그 안에 들어간 내부 로직이 [흙길 보수하기](https://www.acmicpc.net/problem/1911)와 비슷한 로직을 고려해야하다보니 더 그랬던 것 같다.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
	cin.tie(0)->sync_with_stdio(0);
	cout.tie(0);

	int N, C;
	cin >> N >> C;

	vector<int> arr(N);
	for (auto& item : arr)
		cin >> item;

	sort(arr.begin(), arr.end());

	int l = 1;
	int r = arr.back() - arr.front()+1;

	int answer{ 0 };

	while (l < r) {
		const int mid = (l + r) >> 1;

		int c = 1;
		int last = arr.front();

		for (int i{ 1 }; i < arr.size(); ++i) {
			if (arr[i] - last >= mid) {
				c++;
				last = arr[i];
			}
		}

		if (C <= c) {
			answer = mid;
			l = mid + 1;
		}
		else {
			r = mid;
		}

	}


	cout << answer << endl;


}
```
