# [K번째 수](https://www.acmicpc.net/problem/1300)

parametric search를 이용해 답을 구할 수 있다.

아이디어는 다음과 같다. [(.from)](https://www.acmicpc.net/board/view/91180)
- N $\times$ N 크기의 배열에서 나올 수 있는 범위 1 $\le$ value $\le$ (N $\times$ N)에 대해 검색을 수행한다.
- 중간지점 `mid`를 구한다. 구해진 `mid`에 대해 아래 작업을 수행한다.
  - `mid`를 `i`로 나누고 이를 더한다. ( 1 $\le$ i $\le$ N)\*
- 더한 결과 `c`가 `k` 이상일 경우 `mid`값을 답으로 설정하고 식이 끝날 때까지 반복한다.

> Q. `mid`를 `i`로 나누는 이유?  
> 여기서 i는 각 행에 곱해지는 수이다. 만일 mid를 i로 나눈다면, 각 줄마다 mid보다 작은 수의 개수가 반환된다.

이 과정에서 무조건 배열 행열 인덱스의 곱으로 이루어진 값을 찾게되는 이유는 아래와 같다.
1. 만일 찾은 `mid`의 값이 `arr[k]` $\lt$ `mid` $\lt$ `arr[k+1]` 인 경우
   - `c` $\ge$ `k` 분기에 의해 e값이 줄고 다시 검색을 다시 수행.
2. 만일 찾은 `mid`의 값이 `arr[k]` $=$ `mid` 인 경우
   - 기준점 `e`는 `mid`를 벗어나게 되므로, 반복이 종료될 때까지 `answer`의 값 업데이트가 이뤄지지 않음.
3. 만일 찾은 `mid`의 값이 `mid` $\lt$ `arr[k]`인 경우
   - 기준점 `s`가 증가함.

```cpp
#include <iostream>

using namespace std;

int main() {
	long long n, k;
	cin >> n >> k;

	long long s, e, mid;
	s = 1;
	e = n * n;

	long long answer = 0;
	while (s <= e) {
		mid = (s + e) >> 1;

		long long c = 0;
		for (long long i = 1; i <= n; ++i) {
			c += min(mid / i, n);
		}

		if (c >= k) {
			answer = mid;
			e = mid - 1;
		}
		else {
			s = mid + 1;
		}

	}

	cout << answer << endl;

}
```
