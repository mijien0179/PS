# [가장 긴 증가하는 부분 수열 2](https://www.acmicpc.net/problem/12015)

## 해결
기본적인 이진 탐색이 정렬된 순차 데이터에서 특정 값을 뽑는 방식이라면, 이 문제는 정렬이 되지 않은 비순차 데이터에 이진 탐색을 어떤 방법으로 응용할 수 있는가에 대한 문제였다고 생각한다.

새로운 배열 `lcs`을 생성하고, 입력 데이터를 하나하나 순회하면서 현재 선택된 입력 데이터 `A`보다 큰 다음 위치에 현재 값 `A`를 갱신하는 방식으로 처리하였다. 물론, 다음 위치가 존재하지 않은 경우라면 새로 기입하는 것이고.

그래도 몇 달 풀었다고 큰 고민 없이 풀은 문제였다. 다만 생각의 전환이 필요할 뿐. 그걸 고려하면 G2 문제라고는 생각이 들지 않을 정도로 쉬운 풀이었다.

```cpp
#include <iostream>
#include <vector>

#define endl "\n"

using namespace std;

int main() {
	cin.tie(0)->sync_with_stdio(0);
	cout.tie(0);

	int N;
	cin >> N;

	vector<int> lcs;

	int value;
	for (int i = 0; i < N; ++i) {
		cin >> value;
		auto index = 0;
		
		int l = 0, r = lcs.size();
		{
			while (l < r) {
				int mid = (l + r) >> 1;

				if (lcs[mid] < value) {
					l = mid + 1;
				}
				else r = mid;
			}
		}

		if (l == lcs.size()) {
			lcs.push_back(value);
		}
		else {
			lcs[l] = value;
		}

	}

	//for (auto item : lcs)
	//	cout << item << " ";
	//cout << endl;

	cout << lcs.size() << endl;

}
```
